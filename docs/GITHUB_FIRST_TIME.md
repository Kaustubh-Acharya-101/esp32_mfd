# GitHub: first-time guide

This repository is published under the GitHub account `Kaustubh-Acharya-101`.

## Make changes with GitHub Desktop

1. Install GitHub Desktop from https://desktop.github.com/.
2. Sign in with the same GitHub account.
3. Select **File → Clone repository** and choose `esp32_mfd`.
4. Edit files in the local repository folder. Open the Arduino sketch with Arduino IDE.
5. Return to GitHub Desktop and review the changed files.
6. Enter a short summary, such as `Update GPS page layout`.
7. Select **Commit to main**, then **Push origin**.

## Browser upload

On the repository page select **Add file → Upload files**, drag files into the upload area, enter a commit message, and select **Commit changes**.

## GitHub terms

- **Repository:** online project folder and history.
- **Commit:** saved snapshot of changes.
- **Push:** send local commits to GitHub.

Never upload passwords, API keys, tokens, or private telemetry logs.
